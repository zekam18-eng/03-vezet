# 03-Везём

Приложение для заполнения карт вызова СМП, протоколов сердечно-лёгочной
реанимации и локального статуса. В базе — 280 диагнозов с шаблонами
карт и кодами МКБ, 15 случаев реанимации (полная структура протокола
СЛР: разделы, справочники оборудования, три таблицы-хронометража по
минутам). Плюс — вкладка «Подкрадули»: подтягивание карты вызова по
номеру наряда напрямую с сервера станции СМП.

Два варианта в этом репозитории:

## 1. Desktop-приложение (Windows/Linux/macOS)

`main.py` + `database.py` + `patientnote.db` — PySide6 + SQLite.

```bash
pip install PySide6
python main.py
```

Сборка `.exe`:
```
pip install pyinstaller
python -m PyInstaller --onefile --windowed --add-data "patientnote.db;." --name 03-Vezem main.py
```

Если после сборки не отображается PDF во вкладке «Подкрадули» —
пересобери с `--collect-all PySide6` (подтянет все Qt-плагины для
рендера PDF).

## 2. Веб-версия / Telegram Mini App

Папка `webapp/` — самостоятельная страница (HTML/CSS/JS, без бэкенда),
вся база из 280+15+локального статуса зашита в `data.json`. Работает
как обычный сайт и как мини-приложение внутри Telegram.

- 4 вкладки: Карта СМП, Реанимация (с полным протоколом СЛР и
  таблицами-хронометражами), Локальный статус, Подкрадули
- Поиск, добавление своих диагнозов/случаев, редактирование,
  копирование готового текста
- Сохранение — локально в браузере/у пользователя Telegram (не
  синхронизируется между устройствами)
- «Подкрадули»: вводишь номер наряда — открывает карту в браузере
  через `Telegram.WebApp.openLink()`. **Важно:** сервер карт
  (`212.45.19.34`) — внутренний адрес станции СМП, доступен только из
  рабочей сети/VPN. Из обычного мобильного интернета не откроется.

### Публикация на GitHub Pages

1. Settings → Pages → Source: Deploy from a branch → Branch: `main`,
   папка `/webapp`.
2. Через пару минут страница будет доступна по адресу вида
   `https://<юзернейм>.github.io/<репозиторий>/`.

### Подключение как Telegram Mini App

1. Открой `@BotFather` в Telegram → `/newbot` (если бота ещё нет).
2. `/mybots` → выбери бота → `Bot Settings` → `Menu Button` →
   `Configure Menu Button` → вставь ссылку на GitHub Pages из шага выше.
3. Открой бота в Telegram — кнопка меню откроет мини-приложение.
